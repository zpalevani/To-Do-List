# My First To-Do List

A small browser-based task manager built with HTML, CSS and JavaScript.

## Getting started

Clone or download this repository, then open `index.html` in a browser. No package installation or build step is required.

## Features

- Add tasks with optional due dates.
- Edit, delete and mark tasks complete.
- Save tasks in browser local storage.
- Open the reward modal after completing five tasks.

## Files

- `index.html`: page structure
- `style.css`: styling
- `code.js`: task management and persistence

Tasks are stored locally in the browser, not synced across devices. Clearing browser site data may remove them.
